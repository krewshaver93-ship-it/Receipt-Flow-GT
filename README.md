# Receipt Flow GT - Soporte y Políticas

## Política de Privacidad
Receipt Flow GT™ se compromete a proteger la privacidad de sus usuarios. 
1. **Datos recopilados:** Nuestra aplicación solo accede a los datos estrictamente necesarios de las Hojas de cálculo de Google (Google Sheets™) para procesar recibos bajo la acción directa del usuario.
2. **Uso de la información:** No almacenamos, compartimos ni transmitimos datos personales o financieros a servidores externos de terceros.
3. **Seguridad:** Todo el procesamiento se realiza de forma local y segura a través de las APIs oficiales de Google.
*Google Workspace™ y Google Sheets™ son marcas comerciales de Google LLC.*

## Términos de Servicio
Al utilizar el complemento Receipt Flow GT™, usted acepta que:
1. El servicio se proporciona "tal cual" para la automatización de flujos de recibos en Google Sheets™.
2. Usted es responsable de la exactitud de los datos que procesa.
3. El uso está sujeto a los límites de cuota estándar impuestos por Google Workspace™.

Si tienes problemas con el complemento, necesitas ayuda con la configuración o quieres reportar un error, por favor abre un reporte en este repositorio o contáctanos directamente a nuestro correo de soporte técnico.
